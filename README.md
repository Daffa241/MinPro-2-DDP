PENJELASAN TIAP OUTPUT


Output pertama menampilkan input login dengan memasukkanusername dan password sesuai dengan data yang ada didalam dictionary, apabila login sebagai admin maka akan muncul tampilan login berhasil dan langsung memunculkan menu pilihan 1 - 5.
<img width="1449" height="381" alt="Screenshot 2025-09-28 182622" src="https://github.com/user-attachments/assets/c40f25c1-5111-46c6-910d-2ca5657dc823" />


Apabila login sebagai user, maka hanya akan menampilkan dua pilihan yaitu lihat game berdasarkan status dan keluar. Kenapa tidak menampilkan pilihan menu lainnya? dikarenakan menu pilihan seperti tambah game, hapus game serta update game hanya bisa diakses ketika login sebagai admin.
<img width="1454" height="279" alt="Screenshot 2025-09-28 183439" src="https://github.com/user-attachments/assets/75c6f1bf-4777-4be6-b6c8-71a46b517ce8" />


Jika admin maupun user gagal memasukkan username atau password dengan benar sebanyak 3x, maka admin atau user tidak bisa login kedalam program.
<img width="1459" height="380" alt="image" src="https://github.com/user-attachments/assets/3d90ea02-40fd-43b0-83d4-0fb1a98e2685" />

Jika memilih opsi 1 Tambah Game, maka admin diminta untuk memasukkan ID game, judul, genre, platform, tahun rilis versi dan status game. Setelah semua input telah dimasukkan oleh admin, maka game berhasil ditambahkan.
<img width="1460" height="520" alt="Screenshot 2025-09-28 195247" src="https://github.com/user-attachments/assets/253cac68-80ed-4a46-a2d5-997f602745b7" />


Pada opsi menu 2 merupakan opsi untuk melihat daftar game apa saja yang sedang dalam status On Sale maupun Off Sale, user maupun admin akan diminta untuk memilih daftar game dengan status apa yang ingin mereka lihat. Perspektif admin dan juga user akan sama apabila keduanya memilih opsi ini.
<img width="1457" height="531" alt="Screenshot 2025-09-28 201521" src="https://github.com/user-attachments/assets/4d5f10d7-cccd-4882-a672-22b8f3abde20" />


Opsi 3 merupakan menu yang dimana hanya bisa diakses oleh admin, pada opsi ini admin bisa memasukkan versi terbaru pada game yang dipilih berdasarkan ID game yang telah dipilih oleh admin, kemudian admin bisa memasukkan versi terbaru pada game dan telah meng-update game yang dipilih berdasarkan ID game.
<img width="1458" height="263" alt="Screenshot 2025-09-28 201818" src="https://github.com/user-attachments/assets/3425cefd-f0a4-4c30-8d53-40c82bf71c19" />


Jika admin salah memasukkan ID game untuk melakukan update, maka program akan menunjukkan "ID game tidak ditemukaan".
<img width="1450" height="238" alt="Screenshot 2025-09-28 205813" src="https://github.com/user-attachments/assets/64a56d3b-6de9-41f4-9905-b0e4b82e49eb" />



Opsi 4 adalah opsi yang hanya bisa diakses oleh admin. Pada opsi ini admin bisa menghapus game yang telah dimasukkan ke dalam list game atau dictionary berdasarkan ID game yang dipilih oleh admin.
